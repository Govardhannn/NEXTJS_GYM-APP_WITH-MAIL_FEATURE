Krishna Elite Fitness — Gym Web App
Krishna Elite Fitness is a modern, responsive gym website built with Next.js that delivers a premium digital experience for fitness enthusiasts.
🚀 Core Features
- Modern landing page with hero section and strong branding
- Workout programs and featured bootcamps
- Interactive gym gallery with responsive grid
- Membership pricing (Quarterly, Half-Yearly, Yearly)
- BMI calculator with instant health feedback
- Contact form integrated with backend mail service
- Premium UI with glassmorphism and gradient design


🧩 Component Architecture
- Navbar
- Hero
- WorkoutSection
- OfferingPic (Gallery)
- PriceDetails
- Contact
- BMICalculator
- Footer
🛠 Tech Stack
Frontend:
- Next.js
- TypeScript
- Tailwind CSS
- Next/Image
Libraries:
- Axios
- React Toastify
- React Spinners
- Lucide React
Backend:
- Node.js
- Express

⚙️ Installatio
git clone https://github.com/Govardhannn/NEXTJS_GYM-APP_WITH-MAIL_FEATURE

- Install Dependencies:
- npm install
- PORT=4000
- npm run dev
